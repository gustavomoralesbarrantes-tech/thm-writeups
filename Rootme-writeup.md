# TryHackMe - RootMe Write-up

A practical penetration testing write-up for the **RootMe** room on [TryHackMe](https://tryhackme.com/), documenting the complete attack path from reconnaissance to privilege escalation.

The assessment covers:

* 🔎 Network reconnaissance with **Nmap**
* 🌐 Web enumeration with **WhatWeb** and **Gobuster**
* 📂 Directory and file-upload enumeration
* 💻 Web shell and command execution
* 🐚 Reverse shell with **Netcat**
* 🔍 Local enumeration
* 🔐 SUID-based privilege escalation
* 🐍 Python SUID exploitation
* 👑 Root access

The write-up follows a practical penetration testing methodology:

**Reconnaissance → Enumeration → Initial Access → Reverse Shell → Post-Exploitation → Privilege Escalation → Root**

> ⚠️ This repository is intended for educational purposes and documents techniques performed exclusively against a controlled TryHackMe lab environment.
